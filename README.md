SEÇÃO: COMO POSSO TE AJUDAR?

Criar cards elegantes para os principais serviços.

1. Acidente de Trabalho
Para trabalhadores que sofreram quedas, cortes, perfurações ou outros acidentes durante suas atividades.

2. Doença Ocupacional
Casos envolvendo dores na coluna, cervical, lombar, tendinite, esforço repetitivo, carregamento de peso ou problemas causados pelas condições de trabalho.

3. Acidente de Trajeto
Orientação para acidentes ocorridos durante o deslocamento relacionado ao trabalho.

4. Verbas Rescisórias
Análise dos valores e direitos relacionados ao encerramento do contrato de trabalho.

5. Insalubridade
Orientação para profissionais expostos a condições de trabalho prejudiciais à saúde.

6. Direito Previdenciário
Orientação relacionada a benefícios previdenciários e auxílio-maternidade.

IDENTIDADE VISUAL

Usar o Instagram da Dra. Jaqueline como principal referência estética.

A identidade deve transmitir:

- confiança;
- autoridade;
- sofisticação;
- proximidade;
- segurança.

Paleta inspirada no Instagram:

- vinho / bordô como cor principal;
- bege / off-white como fundo;
- dourado em pequenos detalhes;
- branco;
- marrom ou preto para textos.

Não utilizar azul padrão de escritórios de advocacia.

A página precisa manter a identidade visual que ela já utiliza no Instagram.

Tipografia:
Utilizar uma fonte serifada elegante nos títulos combinada com uma fonte sans-serif limpa nos textos.

ESTILO

Visual sofisticado e premium, mas sem parecer um escritório jurídico extremamente corporativo.

A profissional é o centro da comunicação.

Evitar excesso de:
- martelos de juiz;
- balanças gigantes;
- tribunais;
- imagens genéricas de banco de imagens.

Priorizar:
- fotos reais da Dra. Jaqueline;
- tipografia;
- espaços em branco;
- detalhes dourados;
- cards;
- elementos discretos relacionados à advocacia.

DESIGN

Desenvolver mobile-first, considerando que a maior parte do tráfego provavelmente virá de Instagram e Meta Ads.

No celular adicionar um botão fixo inferior:

"Falar pelo WhatsApp"

O site deve ter:
- carregamento visual rápido;
- navegação simples;
- animações discretas;
- boa hierarquia visual;
- seções curtas;
- CTAs frequentes.

Não criar menu complexo.

A LP deve parecer uma página de aquisição, não um site institucional.

IMPORTANTE SOBRE A COMUNICAÇÃO JURÍDICA

Não prometer vitória, indenização, valores ou resultado garantido.

Utilizar linguagem como:
"entenda seus direitos"
"análise do seu caso"
"orientação jurídica"
"verifique quais direitos podem existir"

O objetivo é gerar confiança e contato sem utilizar promessas de resultado.
